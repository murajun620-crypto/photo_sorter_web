# PhotoSorter — GitHub Pages + PC内のGPU認識

[画面を開く](https://murajun620-crypto.github.io/photo_sorter_web/)

このリポジトリは画面だけを配信します。写真の読み込み・GPU認識・プロジェクト・人物登録とOK／NGの保存・圧縮出力は、利用者のPC内で動くPhotoSorter Local 2.8.0が担当します。

## 使い方

1. 初回だけPC側の **Start-PhotoSorter.cmd** を起動して、ブラウザとの接続を登録します。必要なら **PCに接続する** を押し、ブラウザのローカル接続を許可してください。
2. PC側の **Register-Autostart.cmd** でWindowsサインイン時の自動起動を登録します。次回以降、同じブラウザではPagesを開くだけで使えます。PC側だけがバックグラウンドで起動します。解除は **Unregister-Autostart.cmd** です。
3. 写真フォルダを選び、登録・解析・OK／NG修正を行います。登録内容と訂正はPC内へ保存されます。
4. **プロジェクトを保存** で名前を付けて保存し、**新規プロジェクト** で現在の人物登録・登録した顔・OK／NGを引き継ぎ、写真一覧とイベントを空にして始められます。前の作業は保存され、**プロジェクトを開く** の選択欄から戻せます。最後に開いていたプロジェクトは再起動後も復元されます。

既存のPC版で保存したデータベースをそのまま使います。認識モデル・特徴量・判定設定の変更や再登録は不要です。

人物の選択欄の **人物未分類** で、解析済み・人物なしの写真を絞り込めます。PC版2.4.0からは背番号のGPU読み取りにも対応します。

## 基本の流れ

1. **写真フォルダを開く**。Windows標準のエクスプローラー形式の選択画面でフォルダーを選びます。PC内のJPEG・PNGをサブフォルダも含めて読み込みます。
2. **試合を登録**。日時から自動作成するか、手動で写真の範囲を指定します。読み込み時に仮登録済みならその試合を使います。
3. **チームと味方**。保存したチーム名簿と、実際に着たユニフォームを選びます。初めてなら「チーム名簿を編集」や「味方の見本を登録・管理」から追加してください。
4. **相手のユニフォーム**。その試合の相手のシャツ部分を四角で囲んで登録します。
5. **写真を解析**。横の **背番号認識** は初期状態でオンです。読み込んだ全写真の顔を先に解析し、その後、設定済みの試合の背番号を認識します。一覧の試合・日付・人物フィルタでは処理対象を限定しません。
6. 写真を開き、顔・背番号の結果を **OK／NG** で訂正します。登録と訂正はPCへ保存します。
7. 必要なら日付・イベント・上限容量を設定し、**フォルダへ出力**します。Windows標準の選択画面で保存先を指定してください。元写真は上書きしません。

フォルダーの選択はPC側が開きます。Windows画面の **キャンセル**、またはブラウザの処理欄の **キャンセル** で中止できます。選択中も画面の状態確認は止まりません。選択をキャンセルした場合は写真の読み込み・出力を行いません。場所を直接入力する従来の操作も利用できます。

背番号認識をオンにして試合がない場合は、全写真の顔認識を完了した後に試合登録の案内を表示します。未割り当て写真やユニフォーム・番号表の不足も理由を表示します。設定後に同じ解析ボタンを押すと、保存した顔の解析結果を使って背番号を確認できます。**背番号認識をオフ**にすると顔認識だけを実行し、保存済みの背番号結果・OK／NGは保持します。選択はプロジェクトごとに保存し、新規プロジェクトはオンで始めます。

顔の初回登録は、折りたたみの **人物の顔を登録・管理** から行えます。写真を開いて顔を選び、検出されない顔は四角で囲んで登録してください。登録や1枚の顔解析では、背番号認識を自動実行しません。

## 背番号と試合

1. 試合登録を「自動」にして読み込むと、撮影が **30分以上** 空いた所と日付の変わり目で **試合1・試合2…** を仮登録し、写真を割り当てます。既存写真は **日時から試合を自動作成** を押してください。間隔の変更、試合名・割り当ての手直しができます。手動修正と設定済みの試合は再推定で保持します。撮影時刻のない写真は初期設定では割り当てません。
2. 一覧の **撮影日時：新しい順／古い順** で日時の降順・昇順を切り替えます。既存の写真もEXIFの時刻を補完します。時刻がない場合は更新日時・日付で表示します。元写真は変更しません。
3. **味方の見本を登録・管理（PC保存）** に名前を付け、写真のシャツを囲んで見本を登録します。新規プロジェクトとPC再起動後も使えます。以前の試合内の味方見本は **共通へ** で共通保存できます。
4. 試合ごとに **この試合で使う味方の種類** だけを選び、相手の見本を登録します。番号と人物は **チーム名簿（PC保存）** の **背番号 → 人物** に一度登録すると、そのチームを選ぶほかの試合でも使えます。4種類全部を自動的に味方扱いしません。同じフォルダの別試合にも各写真の設定を使います。
5. **背番号認識をオンにして「写真を解析」** を押し、写真を開いてOK／NGで訂正します。番号と味方の見本の両方が合う場合だけ人物を付けます。似た色・重複番号・不明な番号は保留します。背番号の訂正は顔の登録例へ混ぜません。

新規プロジェクトには人物・顔のOK／NG・PC共通4種類・番号表を引き継ぎ、写真・試合・相手の見本・試合だけの番号変更は空で始めます。PC側の共通見本はdata/uniforms.sqlite3に保存します。


**試合登録の選択**：サイドバー・新規プロジェクト・写真フォルダの読み込み画面で **自動／手動／登録しない** を選べます。自動は30分間隔などで仮登録、手動は「＋ 試合」から登録、「登録しない」は試合を作らず顔・日付・イベントで整理します。後で変更でき、既存の試合は消しません。

**チーム名簿と試合だけの変更**：**＋ チーム** で名前を付け、**保存・編集するチーム** を選んで背番号と人物を登録します。PCへ自動保存し、別試合・別プロジェクトでも選ぶだけで呼び出せます。新しい試合には、ここで選んだチームを初期設定します。既存の試合は変更しません。

各試合の **この試合の味方チーム** で使用する名簿を指定してください。同じ背番号でも他チームの人物は混ざりません。味方・相手の見本、選んだユニフォーム、名簿を使うかどうか、試合だけの番号変更・背番号OK／NGも試合とチームごとに保存します。別チームへ切り替えると未設定の見本は登録が必要で、元のチームへ戻すと以前の設定・訂正が戻ります。

チーム名は変更できます。新しいチームを作るときは、表示中の名簿をコピーすることもできます。番号登録の **編集 → 保存するチーム** から別チームへ移せるため、人物を登録し直す必要はありません。同じチーム内の同番号に複数名がいれば自動確定しません。保存先はPC内の **data/uniforms.sqlite3** です。

以前のPC共通名簿は **チーム1** に引き継ぎ、既存試合の番号変更・見本・OK／NGも保持します。チーム1は実際の名前へ変更してください。呼び出した名簿の人物が別の保存済みプロジェクトにだけ存在する場合は、その人物の登録顔・OK／NGをPC内で引き継ぎます。人物の同一性は保存したIDで確認し、名前だけでは結び付けません。

認識モデルや写真はPC内に置きます。モデル・前処理・保存・GPU実行はPC版のJERSEY-NOTES.mdを参照してください。子供・友人の実写真での正解率は未測定です。

バージョン表示の右の **更新確認** は、公開版のバージョン情報だけを取得します。更新があれば **画面を更新する** で再読み込みできます。人物登録・OK／NG・プロジェクトはPCに保持します。PC側の認識プログラムの更新は別途必要です。

## 通信と保存

- PagesはHTML・CSS・JavaScriptのみを配信します。写真・人物名・ファイルパス・OK／NGの送信先には使いません。
- 画面のAPI通信先は `http://127.0.0.1:8765` に固定し、Content Security Policyでも接続先を限定します。
- 写真と顔のサムネイルは、PC側から認証付きで取得してブラウザ内のBlobとして表示します。認証情報を画像URLへ付けません。
- PC側はlocalhostだけで待ち受け、指定したPagesのOriginだけにCORSを許可します。認証なしで写真や保存データを取得できません。
- 接続用の起動トークンはURLのフラグメントで渡し、読み取り直後に画面のURLから除去します。フラグメントはGitHubへのHTTPリクエストに含まれません。
- 人物登録とOK／NGはプロジェクトごとにPC側のSQLiteに保存します。ブラウザのlocalStorageにはPCとの接続情報だけを保持します。サイトデータを消した場合は初回の接続登録をやり直してください。
- 写真の取得と操作は現在のプロジェクトIDも確認し、別のタブで切り替えた後の古い画面から別プロジェクトを誤操作できないようにします。
- 更新確認では、このサイトの `version.json` だけをGETします。認証情報は送らず、CSPも写真用の127.0.0.1とこのバージョン情報のURLだけへ接続を限定します。

PC側の認識モデル・ライブラリ・データベース・利用者の写真を、このリポジトリへ入れないでください。新しい学習済みモデルには提供元の配布条件があり、ここでは再配布しません。

以前のブラウザ内認識のソースや比較画面は履歴・診断用として残していますが、現在のトップ画面はPC連携版です。認識モデルはPC側で起動します。
