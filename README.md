# PhotoSorter — GitHub Pages + PC内のGPU認識

[画面を開く](https://murajun620-crypto.github.io/photo_sorter_web/)

このリポジトリは画面だけを配信します。写真の読み込み・GPU認識・人物登録とOK／NGの保存・圧縮出力は、利用者のPC内で動くPhotoSorter Local 2.1.0が担当します。

## 使い方

1. PC側の **Start-PhotoSorter.cmd** を起動します。認証付きでPagesの画面が開きます。
2. **PCに接続する**を押します。ブラウザにローカル接続の許可が出た場合は許可してください。
3. 写真フォルダを選び、登録・解析・OK／NG修正を行います。登録内容と訂正はPC内へ保存されます。

既存のPC版で保存したデータベースをそのまま使います。認識モデル・特徴量・判定設定の変更や再登録は不要です。

## 通信と保存

- PagesはHTML・CSS・JavaScriptのみを配信します。写真・人物名・ファイルパス・OK／NGの送信先には使いません。
- 画面のAPI通信先は `http://127.0.0.1:8765` に固定し、Content Security Policyでも接続先を限定します。
- 写真と顔のサムネイルは、PC側から認証付きで取得してブラウザ内のBlobとして表示します。認証情報を画像URLへ付けません。
- PC側はlocalhostだけで待ち受け、指定したPagesのOriginだけにCORSを許可します。認証なしで写真や保存データを取得できません。
- 接続用の起動トークンはURLのフラグメントで渡し、読み取り直後に画面のURLから除去します。フラグメントはGitHubへのHTTPリクエストに含まれません。
- 人物登録とOK／NGはPC側のSQLiteに保存します。ブラウザにはタブ単位の接続情報だけを保持します。

PC側の認識モデル・ライブラリ・データベース・利用者の写真を、このリポジトリへ入れないでください。新しい学習済みモデルには提供元の配布条件があり、ここでは再配布しません。

以前のブラウザ内認識のソースや比較画面は履歴・診断用として残していますが、現在のトップ画面はPC連携版です。認識モデルはPC側で起動します。
