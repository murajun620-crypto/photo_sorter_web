# PhotoSorter — GitHub Pages + PC内のGPU認識

[画面を開く](https://murajun620-crypto.github.io/photo_sorter_web/)

このリポジトリは画面だけを配信します。写真の読み込み・GPU認識・プロジェクト・人物登録とOK／NGの保存・圧縮出力は、利用者のPC内で動くPhotoSorter Local 2.3.0が担当します。

## 使い方

1. 初回だけPC側の **Start-PhotoSorter.cmd** を起動して、ブラウザとの接続を登録します。必要なら **PCに接続する** を押し、ブラウザのローカル接続を許可してください。
2. PC側の **Register-Autostart.cmd** でWindowsサインイン時の自動起動を登録します。次回以降、同じブラウザではPagesを開くだけで使えます。PC側だけがバックグラウンドで起動します。解除は **Unregister-Autostart.cmd** です。
3. 写真フォルダを選び、登録・解析・OK／NG修正を行います。登録内容と訂正はPC内へ保存されます。
4. **プロジェクトを保存** で名前を付けて保存し、**新規プロジェクト** で現在の人物登録・登録した顔・OK／NGを引き継ぎ、写真一覧とイベントを空にして始められます。前の作業は保存され、**プロジェクトを開く** の選択欄から戻せます。最後に開いていたプロジェクトは再起動後も復元されます。

既存のPC版で保存したデータベースをそのまま使います。認識モデル・特徴量・判定設定の変更や再登録は不要です。

人物の選択欄の **人物未分類** で、解析済み・人物なしの写真を絞り込めます。PC版2.3.0からは背番号のGPU読み取りにも対応します。

## 背番号と試合

1. **＋ 試合** で試合を作り、**写真をこの試合に割り当て** からファイル名の範囲を設定します。写真ごとに試合を変更することもできます。同じフォルダに複数試合があっても、それぞれの試合の設定を使います。
2. 読み込んだ写真から **味方／相手の見本を登録** し、シャツの部分を四角で囲みます。両方の見本が必要です。別配色やGKは見本を追加してください。
3. **背番号 → 人物** を手動で登録し、**表示中の背番号を読む** を押します。写真に設定した試合の番号表とユニフォーム見本が両方合う場合に人物を付けます。試合未設定・似た色・番号不明・同じ番号の複数人物は自動確定しません。
4. 写真の **背番号と試合** からOK／NGで訂正します。背番号の判定例は顔の登録例へ混ぜません。試合ごとの設定と訂正はPCに保存します。

認識モデルや写真はPC内に置きます。モデル・前処理・保存・GPU実行はPC版のJERSEY-NOTES.mdを参照してください。子供・友人の実写真での正解率は未測定です。

バージョン表示の右の **更新確認** は、公開版のバージョン情報だけを取得します。更新があれば **画面を更新する** で再読み込みできます。人物登録・OK／NG・プロジェクトはPCに保持します。PC側の認識プログラムの更新は別途必要です。

## 通信と保存

- PagesはHTML・CSS・JavaScriptのみを配信します。写真・人物名・ファイルパス・OK／NGの送信先には使いません。
- 画面のAPI通信先は `http://127.0.0.1:8765` に固定し、Content Security Policyでも接続先を限定します。
- 写真と顔のサムネイルは、PC側から認証付きで取得してブラウザ内のBlobとして表示します。認証情報を画像URLへ付けません。
- PC側はlocalhostだけで待ち受け、指定したPagesのOriginだけにCORSを許可します。認証なしで写真や保存データを取得できません。
- 接続用の起動トークンはURLのフラグメントで渡し、読み取り直後に画面のURLから除去します。フラグメントはGitHubへのHTTPリクエストに含まれません。
- 人物登録とOK／NGはプロジェクトごとにPC側のSQLiteに保存します。ブラウザのlocalStorageにはPCとの接続情報だけを保持します。サイトデータを消した場合は初回の接続登録をやり直してください。
- 写真の取得と操作は現在のプロジェクトIDも確認し、別のタブで切り替えた後の古い画面から別プロジェクトを誤操作できないようにします。
- 更新確認では、このサイトの `version.json` だけをGETします。認証情報は送らず、CSPも写真用の127.0.0.1とこのバージョン情報のURLだけへ接続を限定します。

PC側の認識モデル・ライブラリ・データベース・利用者の写真を、このリポジトリへ入れないでください。新しい学習済みモデルには提供元の配布条件があり、ここでは再配布しません。

以前のブラウザ内認識のソースや比較画面は履歴・診断用として残していますが、現在のトップ画面はPC連携版です。認識モデルはPC側で起動します。
